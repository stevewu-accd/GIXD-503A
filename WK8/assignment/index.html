Documentation of Process

I wanted to make an infinite scrolling banana animation. So I find a reference image of the banana and created the image of the banana using vertexs and bezierVertexs. Then I used loops to create arrays of bananas across the page. Using the iterator of the loops, I managed to change the coord of each bananas to make them move.

In order to make the bananas loop across the page, I had to use the "%" operation to set the coord of the bananas back to 0 when they go off the canvas. However, the animation feels sketchy if the bananas keep disappearing and pop up across the canvas. So to add a buffer to this transition, I round the width of the canvas up to a number where it can fit another column/row of the bananas. And then I set their coord back to a column/row before entering the canvas. This way you can't see the bananas teleport and it feels like there's infinite # of bananas.
